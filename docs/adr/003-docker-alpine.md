# ADR 003: Використання Alpine Linux для базових Docker-образів

* **Статус:** Прийнято (Accepted)
* **Дата:** 2026-11-17

## Контекст
При контейнеризації мікросервісів системи планування покупок необхідно обрати базовий образ (Base Image) для Node.js та Nginx. Стандартні образи на базі Debian/Ubuntu мають великий розмір (понад 800 MB) і містять багато непотрібних утиліт, що збільшує поверхню атаки (attack surface).

## Рішення
Обрано використання `alpine`-версій офіційних образів (наприклад, `node:20-alpine`, `postgres:15-alpine`, `nginxinc/nginx-unprivileged:alpine`) у поєднанні з Multi-stage builds.

## Наслідки
* **Позитивні:** Зменшення розміру фінального образу в 5–10 разів (до ~50-100 MB). Швидший pull/push образів у CI/CD пайплайнах. Підвищення безпеки за рахунок відсутності зайвих системних пакетів.
* **Негативні (Trade-offs):** Alpine використовує `musl libc` замість стандартної `glibc`. Це може вимагати додаткового налаштування при компіляції деяких C++ залежностей (наприклад, пакетів для обробки зображень у Node.js), хоча для нашого поточного стеку це не є проблемою.
