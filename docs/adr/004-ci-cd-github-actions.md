# ADR 004: Вибір GitHub Actions як CI/CD платформи

* **Статус:** Прийнято (Accepted)
* **Дата:** 2026-11-18

## Контекст
Для реалізації практик Continuous Integration, автоматизації Quality Gates та збірки артефактів необхідно було обрати інструмент CI/CD. Також потрібен реєстр для зберігання Docker-образів (Container Registry).

## Рішення
Обрано використання **GitHub Actions** як CI-платформи та **GitHub Container Registry (GHCR)** як сховища артефактів.
В якості базової політики якості впроваджено перевірку Dockerfile (hadolint) та сканування на вразливості (Trivy SCA). 
Образи тегуються коротким хешем коміту (GIT_SHA) для гарантування незмінності (immutability) артефактів.

## Наслідки
* **Позитивні:** Інструмент безкоштовний, не потребує налаштування власних CI-раннерів. Єдина екосистема з репозиторієм коду. Зручна автентифікація через `GITHUB_TOKEN`.
* **Негативні:** Прив'язка до екосистеми (Vendor Lock-in). Обмежений ліміт безкоштовних хвилин (2000 хв на місяць), чого, проте, достатньо для поточного проєкту.
